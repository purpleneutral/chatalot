# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Chatalot, please report it responsibly.

**Do not open a public issue for security bugs.**

### How to Report

1. **GitHub Security Advisories** (preferred): Use the [Security Advisories](../../security/advisories) tab to report privately.
2. **Email**: Contact the maintainer at [seglamater@pm.me](mailto:seglamater@pm.me) with details of the vulnerability.

### What to Expect

- **Acknowledgment** within 48 hours of your report.
- We will work with you to understand the issue and determine a fix.
- A coordinated disclosure timeline will be agreed upon before any public announcement.

### What to Include

- Description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Affected versions, if known.
- Any suggested fixes or mitigations.

Thank you for helping keep Chatalot and its users safe.
